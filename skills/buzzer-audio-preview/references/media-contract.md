# Score and media contract

Run `bun scripts/buzzer_preview.ts --in score.json --out-dir out [--stem name]` relative to this Skill, or pass its absolute source path from any directory. `--help` prints usage; invalid arguments, JSON or scores exit 2 with `error:` on stderr. Validation completes before output creation. Filesystem write failures may leave an earlier output, so use a fresh directory for an atomic review candidate. The default stem is the input basename without its last extension; an explicit stem is one filename component.

The root is an object containing a nonempty `events` array. Numeric fields must be finite JSON numbers, and integer fields reject fractional values rather than silently truncating them. Optional null configuration/duration fields use defaults or count as absent. Unknown fields are ignored. `tempo_bpm` defaults to 120 and must fit MIDI's 24-bit microseconds-per-quarter field (60000000/16777215 through 60000000 BPM); `ppqn` defaults to 480 and is an integer in 1..32767. MIDI configuration is an object with integer `channel` (0..15, default 0), `program` (0..127, default 80), and `velocity` (0..127, default 96).

Each note event contains `note` (integer MIDI 0..127 or a note name such as C4, D#5, Bb3) or `freq_hz` (positive finite frequency), plus exactly one of `beats`/`ms`. `note` takes precedence when both pitches exist. Frequencies map to the nearest MIDI note without pitch bend and must round into 0..127. Event `velocity` overrides the MIDI default. A rest contains exactly one of `rest_beats`/`rest_ms`. Note fields take precedence over rest fields. Durations are finite and nonnegative; zero-duration events are valid. C4 is MIDI 60 and A4 is 440 Hz.

`audio` contains `waveform` (`square` or `sine`, case insensitive), integer `sample_rate_hz` (1..384000), `volume`, `duty_cycle`, and integer `fade_ms`; the same top-level fields are fallbacks. Defaults are square, 44100 Hz, 0.7, 0.5 and 2 ms. Volume and duty clamp into 0..1 and negative fade clamps to zero. Arbitrary numeric strings and booleans are rejected. Scores are limited to 50000000 PCM frames; individual MIDI deltas and accumulated rests must fit the four-byte 0..268435455 VLQ limit. These checks reject nonrepresentable or impractically large previews with defined diagnostics.

MIDI is format 0 with one track, tempo meta event, program change, sequential note-on/off events and end-of-track. Rests accumulate into the next note-on or end-of-track delta. Each event independently rounds duration to ticks and samples using ties-to-even. WAV is mono signed 16-bit little-endian PCM; frame count is the sum of individually rounded event counts. Note phase continues between notes and pauses during rests. Synthesis uses amplitude `volume * 0.9`, truncates PCM quantization toward zero, and applies a linear fade bounded by both note ends. WAV frequency remains the requested tone frequency; MIDI uses the rounded note. This is a synthesized preview, not a physical acoustic model or an anti-aliased synthesizer.

Run `bun test ./tests/buzzer_preview.test.ts` from this Skill. Tests independently decode MIDI headers/events/deltas and WAV headers/samples, check exact square-wave duty/rests, and compare sine samples with an analytic formula. The sine tolerance is one PCM integer to allow floating point phase/quantization boundaries. These fixtures establish byte/timing behavior and do not establish speaker or device acoustics.
