# Project foundation topic history

## Lifecycle and Compatibility

This topic establishes the long-lived public project boundary, responsibility-based language policy, independent maintenance contract, and documentation presentation requirements. It preserves the public Skill membership and existing operational contracts.

## Background

The project has a public source and Agent VM contracts, while portions of its maintenance tooling originated in a consumer-specific environment. Reusable requirements are retained; private orchestration, actual deployment information, persona, and runtime integration remain outside the public source.

[ADR 0028](../../adr/0028-language-and-runtime-policy.md) records the accepted language/runtime decision. The script matrix distinguishes that target from source implementations, and IMPLEMENTATION.md records verified coverage separately.
